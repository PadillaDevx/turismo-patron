# Turismo Patrón · Landing page

Landing de **Turismo Patrón**, transporte turístico y privado desde Los Altos de Jalisco.
Sin backend: las cotizaciones se envían por WhatsApp.

Hecha con React + Vite + Tailwind CSS v4 + SweetAlert2.

## Desarrollo

```bash
npm install
npm run dev
```

## Editar contenido

Teléfono, vehículos, destinos y preguntas frecuentes están en `src/data.js`.
Las imágenes propias viven en `public/img/`.

## Publicación

Cada push a `main` se publica automáticamente en GitHub Pages
(workflow en `.github/workflows/deploy.yml`).
